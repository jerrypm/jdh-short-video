I keep a scratch file of repos worth a second look.

Most weeks it fills with noise: a wrapper, a rewrite of something that already
worked, somebody’s weekend parser.

I opened it this week to clean it out and ended up reading the whole thing
instead.

Nothing In The Logs

Nothing In The Logs Claude Fable 5.1 can drop the reasoning you

paid for without raising a single error. The check that…

21zerixpm.medium.com

Nine repos. Six of them don’t install as a library, a binary, or a service.

They install as instructions for an agent: a SKILL.md and a few folders your
agent reads.

I’ve written Swift long enough to watch a couple of packaging conventions
come and go. This one showed up without an announcement and already
has Google in it.

Here they are, in the order I saved them, with what each one actually is.

1. ECC 

➞

 the maximalist

affaan-m/ECC

 · ~247k stars · MIT

The Anthropic hackathon winner’s entire Claude Code setup: 286 skills, 68
agents, 23 lifecycle hooks.

I cloned and measured this one properly last week.

The skill index alone costs about 21,500 tokens per session on a full install,
so take the minimal profile and the six skills that match your stack.npx ecc-
universal setup

Read 

a gents/swift-re viewer. md

 even if you never install it.

2. CLI-Anything 

➞

 the one I didn’t expect

HKUDS/CLI-Anything

 · 48.5k stars · Apache 2.0

This is the idea I’ve thought about most since I saved it.

It generates command-line interfaces for desktop software that never had
one: Blender, GIMP, LibreOffice, FreeCAD, QGIS, Godot, OBS, Krita, 80+
programs, so an agent can drive them with commands instead of clicking
pixels.

GUI automation is fragile because it automates the wrong layer. Give the
agent a CLI and most of that fragility goes away.

It ships a seven-phase pipeline that reads a program’s source, maps its
capabilities to commands, writes the CLI, generates the tests, and publishes
the package.

There’s a CLI-Hub registry for installing pre-built ones, and 2,280+ tests
passing.

It also auto-generates a SKILL.md for each CLI so agents can discover it,
which is the part that matters for the pattern.

3. screenshot-to-code 

➞

 the veteran

abi/screenshot-to-code

 · 76.8k stars · MIT

Drop in a screenshot, get HTML/Tailwind, React, Vue, Bootstrap, or Ionic
back. It also takes Figma frames and screen recordings.

This one has been around and it shows:

FastAPI backend, React/Vite frontend, a Docker compose file, and a hosted
version at screenshottocode.com if you don’t want to wire up keys.

It runs against Gemini, GPT, Claude, and Replicate.

It’s excellent for the first 80% of a static layout and it will not give you a
component architecture.

For iOS work it produces web output, so treat it as a reference render rather
than something you ship.

4. ScrapeGraphAI 

➞

 scraping that survives a redesign

ScrapeGraphAI/Scrapegraph-ai

 · 29.5k stars · MIT

You describe what you want; it works out how to get it.

The pipelines are graph-based: SmartScraperGraph for one page,
SearchGraph across results, SpeechGraph for audio out.

The reason to care is maintenance.

A CSS-selector scraper breaks the morning the site ships a redesign.

A prompt-driven one usually doesn’t.

It runs against OpenAI, Groq, Azure, and Gemini, or fully local through
Ollama, which is the configuration to use if you’re pointing it at anything you
don’t want leaving your machine.

5. Agent Skills 

➞

 the tell

google/skills

 · 19.4k stars · Apache 2.0

100+ agent skills for Google Cloud, GKE, databases, security, and developer
tooling.

npx skills add google/skills

That command isn’t a Cloud SDK or a Terraform provider.

It’s a skill installer, and it bundles plugins for Claude Code and Codex, which
are competitors’ harnesses.

If someone asked me for evidence that this convention is real rather than a
vibe, this is the entry I’d point at:

Google shipping it inside its own namespace, with first-class support for
other vendors’ agents.

6. DeepSeek Harness 

➞

 the one to watch, carefully

deepseek-ai/deepseek-harness

 · ~210k stars · MIT

An agent framework on an everything-is-a-plugin architecture, with a CLI
and a web UI.

npx @deepseek-ai/dsh web

It has roughly 210,000 stars and 14,900+ commits, and the README calls it a
developer preview with breaking changes expected.

Those two things are accurate at the same time.

Star it, read the plugin architecture, don’t put it under anything you’re on call
for yet.

7. Humanizer 

➞

 35 patterns

blader/humanizer

 · 41k stars · MIT

An agent skill that rewrites AI-generated prose to stop sounding like AI-
generated prose.

It works from a documented pattern list drawn from Wikipedia’s “Signs of AI
writing”: it rewrites once, checks the draft against the patterns and against
the original claims, then rewrites again.

It leaves code, data, and frontmatter alone while it edits prose.

That last detail is why it’s on the list. Most “humanizer” tools happily mangle
a code block.

8. Stop Slop 

➞

 same problem, different method

hardikpandya/stop-slop

 · 16.8k stars · MIT

Stop Slop goes at the same target from a different direction: three categories
of tell (throat-clearing openers and jargon, structural habits like binary
contrasts and false agency, sentence-level rules), plus a five-dimension
rubric covering directness, rhythm, trust, authenticity, and density, scored
out of 50, with 35 as the revision threshold.

Humanizer rewrites. Stop Slop scores, which means you can put it in a loop
or a pre-commit check.

Two independent repos, 57.8k stars between them, solving the identical
problem in the same season. That looks to me like a market forming around
the cleanup cost of everything else on this list.

9. OmniRoute 

➞

 the plumbing

diegosouzapw/OmniRoute

 · 59.7k stars · MIT

An AI gateway: one endpoint in front of 352 providers, 19 routing strategies,
fallback chains, circuit breakers, and MCP server support.

It also advertises 15% to 95% token savings through compression, and
catalogs roughly 1.51 billion free tokens a month across 150+ free providers.

Those are the repo’s numbers, not mine, and the compression range is wide
enough that I’d measure it on your own traffic before repeating it.

The useful part is unglamorous: when one provider degrades, your agent
doesn’t stop.

The pattern, stated plainly

Count how these nine install.

Agent skills and harnesses: ECC, CLI-Anything, google/skills, DeepSeek
Harness, Humanizer, Stop Slop. Six of nine.

Applications: screenshot-to-code, ScrapeGraphAI. Two of nine.

Infrastructure: OmniRoute. One of nine.

Six of nine ship as things you hand to an agent rather than things you call
from your own code.

A year ago this list would have been nine libraries. And two of those six exist
purely to clean up after the other four.

What I’d actually install tonight

Not all of it.

That was the lesson from measuring ECC: a skill you never fire still costs you
index space every session.

Three, in this order.

1. 

stop-slop.

 Smallest of the nine, and the rubric is useful whether or not an

agent ever runs it. Read the five dimensions and you’ll edit your own
writing better.

2. 

google/skills, selectively.

 Pick the categories you actually touch and skip

the ninety you don’t.

3. 

CLI-Anything, but only if you have a GUI program sitting in a workflow.

If you do, it’s the highest-leverage thing here.

The rest get cloned and read, not installed.

One caveat about the numbers

Every star count here is real as of this week, and several of them grew very
fast.

A 210,000-star developer preview tells you about distribution, not about
production readiness.

Read the README, check the last commit date, and look at whether the
Issues tab is full of people using it or full of people failing to install it.

That takes four minutes, and it’s how I decide whether something goes in the
scratch file or on disk.
