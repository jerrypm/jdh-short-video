## Local macOS bundle

Version 0.2 copies the tested uv CPython runtime, Python packages/models, FFmpeg/ffprobe and their non-system dependencies into `dist/`. Existing package license/metadata files and model cards are retained. The bundle includes an inventory of relocated FFmpeg libraries in `Contents/Resources/ffmpeg-libraries.json`. This changes FFmpeg from a runtime system dependency to an included binary for this **local build only**; a distributable release still requires a complete redistribution/license review and the applicable notices/source obligations. The locally generated app icon uses AppKit vector drawing in `script/make_icon.swift`.
